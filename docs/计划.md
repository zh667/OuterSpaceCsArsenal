## 1. 目标与范围

- 把 CS2 的 **35 件枪械**（34 把枪 + 宙斯电击枪）做进秩序新曙光，殖民者可以制造、装备、实战使用。

- 新科技分支（4 个节点）、两台新设备、每把枪一份配方，每把枪 4 个品质档（和原版一致）。
- 发布：创意工坊**仅自己可见**（2026-11-09 用户定）。
- 获取：制造，以及进商人货单和敌人掉落（2026-11-09 用户定）。
- 不做：手雷、刀、C4（以后可以另开一批：手雷模型在 `12_grenades`，22 把刀在 ScCsgoKnives）；皮肤、印花。
- 新增（2026-11-09 用户提）：CS2 探员，方案见第 12 节。

## 3. 游戏里怎么接（0.9.0020 反编译源码查实）

- **枪的外观**：官方模组接口。模组目录 `Resources/Textures/role-customize.xml` 的 `<weapons>`，每把枪给 5 个朝向 PNG（`Texture_T / RT / S / RB / B`），`WeaponType` 用 `handGun`（手枪）、`gun`（长枪）。游戏把它挂到人物 Spine 骨骼上（`SpineCombine.createWeaponAttachment`），挂件名就是 `Name`，武器表的 `*_Slot_Weapon` 填这个名字。
- **枪的数值**：武器表 `T_Weapon`，每把原版枪 4 行（品质 1～4，ID 末位 0～3）。字段有伤害、弹匣、每次出弹数、连发间隔、换弹、射程、命中、伤害类型、穿甲、范围伤害、击倒、减速、硬直、附加效果（`AdditionEffect`）。
- **配方**：`B_Production_List`（材料 `12_<材料>_<数量>`，产出 `18_<武器ID>_1`），挂到设备的 `ProductID`。
- **科技**：`Science`（树上位置 `HexGridX/Y`、前置 `Pre_technology`）→ `Building_unlock` → `G_TechTreeItem`（`AimItem 27_<设备ID>` 解锁设备）。
- **要写 DLL**（沿用终末地炮塔模组 EfTurrets 已验证的做法）：
  - 表格行要由 DLL 在 `initModDef` 里加。数据模组会给行 ID 自动加 `包名_` 前缀，配方的 `18_<武器ID>_1` 这种下划线拼的引用会断（炮塔模组踩过）。
  - 新设备的外观（`generator_BuildClass` 返回自己的类，读自己的 .bin）。
  - CS 原声：原版音效填的是游戏音效编号，新声音要 DLL 加载（第 0 轮验证）。
- **只有部分特效要 Harmony**：伤害结算在 `HurtUtils.hitTarget(target, HurtStruct)`，`HurtStruct.weaponDef` 能认出是哪把枪，但没有官方钩子。暴击、穿透、叠层这类效果只能在这里挂 Harmony Postfix。其余特效用表格字段就能做（第 6 节标了每把枪是哪种）。

## 7. 外观制作流程

1. **5 个朝向渲染**（Blender，原 GLB + 原贴图）：背面（T）、右上斜（RT）、侧面（S）、右下斜（RB）、正面（B），视角对齐原版枪贴图（第 0 轮先量原版 `gun/AK47s`、`handgun/p250s` 等的尺寸、角度、握把位置）。
2. **缩到游戏尺寸**：按 CS 枪的真实长度换算像素，长枪和手枪各自统一比例（AWP 明显比 P90 长）。出两种做法给你选：直接缩小保留原贴图细节，或者用炮塔模组的像素化流程统一成游戏画风。
3. **握把对位**：贴图中心要对上原版挂点。游戏会复制原版模板挂件（长枪 `gun/870*`、手枪 `handgun/jg2*`），**可能沿用模板的显示尺寸**，那样 35 把枪会被拉成一样大。第 0 轮验证；如果真这样，就把每把枪画在和模板同尺寸的画布里，用透明边留出真实长度差。
4. **图标**：用 CS2 原图标缩放。
5. **枪口火光、弹道、命中特效**：用游戏原版的（武器表 `FireType / BulletId / HitHuman` 填原版同类枪的值），不自己画。
6. **自动检查**：5 个朝向都有、透明边干净、握把落在挂点 ±1 像素、长度比例和真枪一致（误差 <5%）。
7. 进游戏截图：白天、夜晚、室内，每个朝向，射击和待机。
